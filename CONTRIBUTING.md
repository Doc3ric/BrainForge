# Contributing to BrainForge

Thank you for your interest in contributing to BrainForge!

## Development Rules
All contributors MUST read and follow `docs/technical/DEVELOPMENT_RULES.md` before writing any code.

## Pull Request Process
1. Ensure your code complies with Laravel Pint (backend) and ESLint/Prettier (frontend).
2. Ensure all tests pass.
3. Update the `API_SPEC.md` and `DATABASE.md` if you are modifying the architecture.
4. Fill out the Pull Request template completely.
